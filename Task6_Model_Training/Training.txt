# MODEL TRAINING

1. Objective

     The objective of the training stage is to build a machine learning model to
     predict customer churn based on engineered features.

2. Dataset

     The final dataset generated after feature engineering and selection was used
     for training the model.

3. Train-Test Split

     The dataset was split into training and testing sets using an 80:20 ratio to
     evaluate model performance on unseen data.

4. Feature Scaling

     StandardScaler was applied to normalize numerical features to ensure all
     features contribute equally to the model.

5. Model Selection

     Logistic Regression was used as the classification model due to its simplicity
     and effectiveness for binary classification problems.

6. Model Training

     The model was trained using the scaled training dataset.

7. Model Saving

     The trained model and scaler were saved for later evaluation and deployment.
