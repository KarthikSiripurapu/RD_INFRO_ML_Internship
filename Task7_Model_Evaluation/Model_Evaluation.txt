# MODEL EVALUATION

1. Objective

    The objective of model evaluation is to measure the performance of the trained
    model on the dataset.

2. Evaluation Metrics

    The following metrics were used:
      - Accuracy
      - Confusion Matrix
      - Classification Report

3. Accuracy

    Accuracy measures the proportion of correctly predicted instances among all
    instances.

4. Confusion Matrix

    The confusion matrix shows the number of correct and incorrect predictions
    made by the model for each class.

5. Classification Report

    The classification report provides precision, recall, and F1-score for churn
    and non-churn classes.

6. Conclusion

    The evaluation results indicate that the model is capable of predicting
    customer churn with reasonable accuracy.
